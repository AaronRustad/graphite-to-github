# Changelog

## 1.0.0 — 2026-10-19

Initial release of Graphite to GitHub.

- Automatically redirects Graphite pull request links to the corresponding GitHub PR in the same tab.
- Supports any GitHub owner and repository, including links with trailing slashes, title slugs, and query parameters.
- Leaves other Graphite pages and embedded content unchanged.
- Processes redirects locally, with no analytics or data collection.

Requires Firefox 142 or newer.
